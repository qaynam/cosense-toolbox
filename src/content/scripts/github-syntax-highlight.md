コードブロックの見た目が、GitHubのダークテーマ風の配色に変わります。暗い背景にキーワードや文字列、コメントなどが色分けされて表示されるので、GitHubを見慣れた人にはおなじみの雰囲気で、コードが読みやすくなります。

入れるだけでコードブロックの配色が切り替わります。
