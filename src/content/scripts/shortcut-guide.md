Cosenseでよく使うキーボードショートカットの一覧（早見表）です。入れて動かすスクリプトではなく、操作を確認したいときに見るリファレンスとして使えます。`Ctrl + r` など一部のキーは、対応するuserScriptを導入すると使えるようになります。

| キー | 動作 | 備考 |
| --- | --- | --- |
| `CMD + i` / `Ctrl + i` | アイコン挿入 | `tab` を1回押してから押すとリンク記法のアイコンを素早く入力 |
| `Ctrl + t` | 日付挿入 | 連打でフォーマット切替 |
| `CMD + g` | 検索バーにフォーカス | CMD+K風 |
| `CMD + e` | エディタにフォーカス | |
| `Ctrl + r` | `[-.icon]`（仕切り線）を挿入 | userScript導入時に有効 |
