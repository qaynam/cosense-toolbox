コードブロックの各行に行番号がつきます。`01`、`02`...とゼロ埋めで枠線付きに表示されるので、コードのどの行かを伝えたり、長いコードを読むときに便利です。今いる行は番号が濃くなり、背景にも色がついて見やすくなります。

番号や色は好みに合わせて調整できます。
